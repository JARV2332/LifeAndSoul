# Life & Soul — Functional Training

Plataforma web premium de entrenamiento funcional: panel de atleta, panel del profesor, coach IA, cocina digital y hub de fisioterapia.

## Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Despliegue

Configurado para [Vercel](https://vercel.com) con `vercel.json` (SPA + build de Vite).
